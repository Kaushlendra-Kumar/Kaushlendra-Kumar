## Featured Projects

### [DPDK Logging Framework](https://github.com/Kaushlendra-Kumar/dpdk-logging-framework)
High-throughput, thread-safe logging engine for telemetry and health-monitoring pipelines.
- **Design:** Singleton core with Chain of Responsibility log routing; mutex-guarded queues for concurrent producers
- **Systems work:** DPDK integration for kernel-bypass packet handling on the hot path
- **Tech:** C++17, DPDK, POSIX threads, GDB

### [Elevator Control System](https://github.com/Kaushlendra-Kumar/elevator-simulator)
Multi-elevator dispatch simulation built around real scheduling theory, not if-else soup.
- **Design:** State + Factory patterns; LOOK disk-scheduling algorithm adapted for elevator dispatch
- **Architecture:** Both distributed-controller and master-controller topologies implemented and compared
- **Tech:** C++, GoogleTest

### [MemeForge](https://github.com/Kaushlendra-Kumar/memeforge)
Full-stack meme creation studio with in-browser ML.
- **Frontend:** Next.js + Konva.js canvas editing, client-side face detection via TensorFlow.js
- **Backend:** Stateless Express API designed for horizontal scaling
- **Tech:** Next.js, Konva.js, TensorFlow.js, Node.js, Express

### [Huffman Encoding Engine](https://github.com/Kaushlendra-Kumar/huffman-engine)
Lossless compression/decompression tool built from first principles.
- **Internals:** Priority-queue tree construction, bit-level I/O, streaming encode/decode
- **Tech:** C++, STL
